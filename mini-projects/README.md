# 🚀 Mini Projects

Ye section C concepts ko small real programs mein combine karne ke liye hai.

Projects ko tab start karo jab required concepts ke basic examples samajh aa jayein.

## 🟢 Beginner

### 1. Simple Calculator

**Concepts:** functions, conditions, input/output

Features:
- Addition
- Subtraction
- Multiplication
- Division
- Menu-based interface

### 2. Number Guessing Game

**Concepts:** loops, conditions, functions

Features:
- User guesses a number
- Attempts count
- Higher/lower hint
- Replay option

### 3. Student Marks Calculator

**Concepts:** arrays, loops, functions

Features:
- Multiple marks input
- Total
- Average
- Maximum
- Minimum
- Grade

## 🧠 Project Rule

Har project ko ek hi baar mein perfect banane ki zaroorat nahi.

Basic version
    ↓
Make it work
    ↓
Clean the code
    ↓
Add one feature
    ↓
Test again
    ↓
Improve

**Project ka goal:** concepts ko combine karna, sirf bada code likhna nahi.
