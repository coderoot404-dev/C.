# 🧪 Practice Challenges

Ye folder **khud problem solve karne** ke liye hai. Yahan pehle problem ko bina existing solution dekhe solve karna hai.

## Rules

1. Problem ko pehle khud samjho.
2. Solution khud likho.
3. Compile aur run karo.
4. Error aaye to error message padho.
5. Solution chal jaye to code ko simpler/better banane ki koshish karo.
6. Sirf answer dekh kar copy nahi karna.

---

## 🏆 Challenge Levels

**Level 1 — Foundation**

Loops, conditions, simple arrays aur basic functions.

**Level 2 — Logic**

Searching, sorting, strings aur 2D arrays.

**Level 3 — Problem Solving**

Pointers + functions + arrays ko combine karo.

**Level 4 — Mini Projects**

Practice problems ko real programs mein combine karo.

> Goal: **pehle logic, phir code.**
